# N14a — isolation and safety verification

Parent: [N14](../../tickets/001-nanoad/N14-isolation-and-safety.md). See [threat model](../../docs/threat-model.md) and [recovery](../../docs/recovery.md).

Strict pure inventory policy refuses missing scope/peer/media/ACL evidence, foreign registered or running VMs, incomplete NIC/guest route/DNS evidence, changed registry, unsafe integrations, unknown counts, foreign or aliased disks, noncanonical paths, changed base digests and interrupted state. It returns model compatibility only and cannot issue a mutation permit. All observations must be trusted; the real comprehensive collector is not supplied by this slice. Read-only typed VBoxManage list vms/runningvms and a bounded name-discarding parser provide a first concrete collection primitive. The current native transport refuses start/stop as before.

Native Windows fixed-name mutex excludes cooperating callers across lab roots/sessions. It is thread-owned, rejects re-entry, never falls back to a local lock and requires reconciliation after every acquisition. The default DACL may refuse other users; this is a safe refusal. It does not lock the hypervisor or cover non-cooperating processes. The Windows path inspector opens every ancestor and the final file, checks reparse attributes, normalized DOS path, fixed local drive, file type, volume/file identity and single link, holds handles during observation, and returns identity only. It does not prove ACLs, preserve the handles through a future mutation, or qualify hostile concurrent path replacement. Windows ASCII canonical-path restriction is intentional.

Run pinned Zig 0.14.1: zig fmt --check build.zig src modules; zig build test; zig build -Doptimize=ReleaseSafe. Tests include path escapes, actual Windows file/hardlink identity, native mutex, child-process mutex exclusion, parser rejection, normalized inventory adverse-state matrix and redacted refusal output. Real VirtualBox configuration, unknown provider fields, other user/config scopes, actual media and network peer enumeration, NTFS ACL/reparse races, guest route checks, full secret review, physical interruption and independent review remain required. No real VM invoked. No mutation CLI or provider changes. Rollback: revert scoped source; preserve state and media.
