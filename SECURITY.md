# Security policy

NanoAD is intended exclusively for disposable, authorised lab environments. Treat lab guests and imported artefacts as untrusted. The project must default to a private network without external routing, shared folders, public port forwards or real credentials. Do not connect it to a production or third-party domain.

There is currently no supported release. For a suspected vulnerability in NanoAD itself, use GitHub's private vulnerability reporting if enabled, or contact the repository maintainer privately before public disclosure. Do not post credentials, exploit data, private logs or personal information in public issues. Report affected commit/version, reproducible conditions in a synthetic lab, impact and relevant sanitised evidence.

The MIT licence applies to NanoAD code only. Obtain Windows media and other proprietary components from authorised sources; no activation bypass or redistribution of modified Windows images is part of this project.
