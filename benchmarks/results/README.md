# Benchmark results

No real AD benchmark has been recorded. Do not infer savings from synthetic tests.

For each candidate publish a sanitised report: run UUID, commit, UTC, exact host/guest/provider build and image hash; configured RAM and peak/idle host/guest measurements; complete physical allocation accounting and build scratch peak; reference comparison, workload latency, native checks, isolation, restart, failed/inconclusive results, and independent reviewer. Raw logs/media stay outside Git. A sample summary or file-data estimate is not sufficient for qualification.

See [execution protocol](../protocol/EXPERIMENTS.md).

The [blank qualification template](qualification-template.json) and [offline review procedure](../../tests/integration/qualification/README.md) are preparation, not observed data. Synthetic test reports never belong in this results directory as measured results. No native measurement or independent qualification has occurred.
